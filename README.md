# Excel 批量数据提取工具

一个基于 Python + Tkinter 的图形化工具：批量遍历文件夹中的多个 Excel 工作簿，按
**指定工作表 + 指定单元格**提取数据，汇总写入一张表，并在首列标注每行数据的来源
（工作簿名称）。

适合场景：多份格式相同的基础数据表（如各部门上报表、各项目台账、月度报表），
需要把其中若干固定单元格的值集中抽取到一张汇总表里做横向对比。

## 功能特性

| 特性 | 说明 |
|------|------|
| 批量扫描 | 遍历指定文件夹下所有 `.xlsx` / `.xlsm` 文件 |
| 自动跳过临时文件 | 忽略 Excel 打开时产生的 `~$` 开头临时文件 |
| 多项提取 | 每行一个提取项，可一次提取多个工作表 / 多个单元格 |
| 合并单元格 | 目标单元格若在合并区域内，自动取左上角单元格的值 |
| 公式无缓存提示 | 单元格为空且原始内容是公式时，记录“公式无缓存结果”提示 |
| 重复项多列 | 同一提取项重复填写，会在汇总表中生成多列，便于对比 |
| 追加 / 覆盖 | 汇总表已存在时可选择追加到末尾、覆盖重建或每次询问 |
| 后台线程 | 提取过程在后台线程执行，界面不卡顿 |
| 进度与日志 | 实时进度条、状态栏、滚动日志，问题项集中列出 |
| 中英文兼容 | 提取项支持半角 `!` 与全角 `！` |

## 界面说明

窗口从上到下分为四个区域：

### 1. 基础数据文件夹
选择**待提取的 Excel 所在目录**。程序会扫描该目录下（不递归子目录）所有
`.xlsx` / `.xlsm` 文件。选择后若“保存文件夹”为空，会自动同步为该目录。

### 2. 提取项
多行文本框，每行一个提取项，格式为 `工作表名!单元格`。默认示例为 `Sheet1!O7`。

### 3. 汇总表保存设置
- **保存文件夹**：汇总表输出目录
- **文件名**：默认 `汇总表`，未写扩展名时自动补 `.xlsx`
- **已存在时**：`询问` / `追加到末尾` / `覆盖重建` 三选一

### 4. 操作区
- **开始提取**：校验输入后启动后台任务
- **清空日志**：清除日志区内容
- **退出**：关闭程序

底部为进度条、状态栏与日志区。

## 快速开始

假设你有三份格式相同名称不同的工作薄放在 `D:\数据`，需要提取每份工作薄中的
`数据表!C5`（填报单位）和 `数据表!F12`（合计金额）两列。

1. **选择文件夹**：点击「浏览…」，选择 `D:\数据`
2. **填写提取项**：
   ```
   数据表!C5
   数据表!F12
   ```
3. **设置保存位置**：保存文件夹选 `D:\数据`，文件名填 `汇总表`
4. **点击「开始提取」**
5. 完成后弹出结果摘要，并在日志区列出有问题的提取项

生成的 `汇总表.xlsx` 内容类似：

| 工作簿名称 | 数据表!C5 | 数据表!F12 |
|-----------|-----------|-----------|
| 名称A      | 填报单位A | 12000     |
| 名称B      | 填报单位B | 9800      |
| 名称C      | 填报单位C | 15600     |

## 提取项格式详解

### 基本格式

```
工作表名!单元格
```

- **工作表名**：Excel 底部标签页名称，区分大小写，需与文件内完全一致
- **分隔符**：半角感叹号 `!` 或全角 `！` 均可
- **单元格**：Excel 单元格地址，如 `A1`、`O7`、`AB123`，**不区分大小写**

### 合法与非法示例

| 输入 | 结果 |
|------|------|
| `Sheet1!O7` | ✅ 合法 |
| `数据表！C5` | ✅ 合法（全角） |
| `Summary!AB123` | ✅ 合法 |
| `Sheet1` | ❌ 缺少 `!` |
| `!A1` | ❌ 工作表名为空 |
| `Sheet1!A0` | ❌ 行号不能为 0 |
| `Sheet1!1A` | ❌ 单元格格式错误 |
| `Sheet1!AAAA1` | ❌ 列字母超过 3 位 |

### 重复项

同一提取项重复填写**不会去重**，而是按顺序生成多列。例如：

```
数据表!C5
数据表!C5
```

会生成两列，列名相同，值也相同。可用于需要并排显示同位置数据的场景。

### 合并单元格

若目标单元格位于合并区域内（且不是左上角），程序会读取该合并区域
**左上角单元格**的值。

## 汇总表输出格式

### 列结构

| 列 | 内容 |
|----|------|
| A 列 | `工作簿名称`（不含扩展名） |
| B 列起 | 每个提取项一列，列名为 `工作表名!单元格` |

### 行结构

- 第 1 行为表头
- 第 2 行起，每个工作簿一行
- 行顺序按文件名字母序排列

### 列宽

A 列固定 22，数据列至少 16，便于查看。

### 单元格为空的情况

- 目标单元格本身为空：写入空值，不记为问题
- 目标单元格为空但原始内容为公式：写入空值，并在日志与结果弹窗中
  记录 `公式无缓存结果`
- 工作表不存在：写入空值，记录 `工作表不存在`
- 文件读取失败：该文件所有提取项写空，记录 `读取失败：<原因>`

> **为什么会出现“公式无缓存结果”？**
> openpyxl 以 `data_only=True` 读取时只能拿到 Excel 上次保存时缓存的计算结果。
> 如果文件由程序生成、从未在 Excel 中打开保存过，公式单元格就没有缓存值，
> 此时会回退读取原始内容，若为公式字符串则给出该提示。用 Excel 打开并保存
> 一次该文件即可解决。

## 已存在汇总表的处理

汇总表路径已存在时，根据「已存在时」选项处理：

### 询问（默认）

弹出对话框：

- **是** → 追加到已有数据末尾
- **否** → 覆盖重建
- **取消** → 中止本次操作

### 追加到末尾

- 打开已有文件，从最后一行之后继续写入
- 若第 1 行全空，则视为空表，从第 1 行开始写表头
- 若第 1 行非空，则**不再写表头**，直接追加数据行
- 注意：追加模式**不会**校验已有表头是否与本次提取项一致

### 覆盖重建

删除原文件内容，重新创建并写入表头与数据。

### 保存失败

若汇总表正被 Excel 打开，保存会触发 `PermissionError`，程序提示：

> 保存失败：汇总表可能正被 Excel 打开，请关闭后重试。

关闭该文件后重新点击「开始提取」即可。

## 常见提示与问题排查

| 现象 / 提示 | 原因 | 处理 |
|------------|------|------|
| 未找到 .xlsx / .xlsm 文件 | 目录为空或只有旧版 `.xls` | 确认目录；`.xls` 需先另存为 `.xlsx` |
| 工作表不存在 | 工作表名拼写不一致 / 大小写不符 | 核对 Excel 标签页名称 |
| 单元格格式错误 | 单元格地址写错 | 使用 `A1` 形式，行号从 1 开始 |
| 格式错误（缺少“!”） | 该行没有分隔符 | 补上 `!` 或 `！` |
| 公式无缓存结果 | 文件由程序生成，公式无缓存值 | 用 Excel 打开并保存一次 |
| 读取失败：... | 文件损坏 / 加密 / 格式异常 | 单独打开该文件排查 |
| 保存失败：汇总表可能正被 Excel 打开 | 目标文件被占用 | 关闭 Excel 后重试 |
| 扫描到的文件数比预期少 | 子目录不递归 | 将文件放到同一层目录，或分批处理 |

### 界面无响应？

提取在后台线程执行，正常情况下界面不会卡死。若文件夹内文件极多
（数百上千个），进度更新会非常频繁，可耐心等待进度条走完。

## 技术说明

### 依赖库

- **openpyxl**：读写 `.xlsx` / `.xlsm`，支持合并单元格、公式读取
- **tkinter / ttk**：标准库 GUI，无需额外安装
- **threading**：后台执行提取，避免阻塞主线程

### 关键实现

- **合并单元格读取**：遍历 `ws.merged_cells.ranges`，命中则改读左上角
- **公式检测**：先用 `data_only=True` 读值；值为空时再用
  `data_only=False` 读原始内容，若为 `=` 开头字符串则标记
- **延迟加载**：仅在需要判断公式时才加载第二份工作簿，减少开销
- **警告屏蔽**：屏蔽 openpyxl 对未知扩展格式的 `UserWarning`

### 已知限制

- 仅支持 `.xlsx` / `.xlsm`，不支持旧版 `.xls`（需另存为新格式）
- 不递归子目录
- 提取粒度为“单元格”，不支持区域 / 整行 / 整列
- 追加模式不校验表头一致性
- 工作表名区分大小写

### 目录结构

```
excel-batch-extractor/
├── excel_batch_extractor.py   # 完整程序（核心逻辑 + GUI + 入口）
├── requirements.txt           # 依赖清单
├── README.md                  # 本文件
└── LICENSE                    # MIT 许可证
```

单文件自包含，无需安装为包，`python excel_batch_extractor.py` 直接运行。
