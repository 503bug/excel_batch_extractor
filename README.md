# Excel 批量数据提取工具

批量提取多个 Excel 工作簿中**指定工作表、指定单元格**的数据（可多项），
写入汇总表并在首列标注数据来源（工作簿名称）。带图形界面、进度条与日志。

## 功能

- 遍历文件夹下所有 `.xlsx` / `.xlsm`（自动跳过 `~$` 临时文件）
- 提取项格式：`工作表名!单元格`，每行一个，支持全角 `！`
- 同一提取项重复填写会生成多列
- 自动处理合并单元格（取左上角值）
- 单元格为空且原为公式时，提示“公式无缓存结果”
- 汇总表支持**追加**或**覆盖重建**，已存在时可询问
- 后台线程处理，界面不卡顿，带进度条与实时日志
